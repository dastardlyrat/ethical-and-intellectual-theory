# ICHK

**Author-supplied definition:** The **mechanism by which something is poisoned for rejection**.

## Scope

ICHK is recorded as the author's name for a proposed rejection-oriented poisoning mechanism. Its expansion, implementation, technical operation, and criteria for demonstrating an instance are **not specified** in the available definition. The acronym is intentionally **not expanded** here.

The word *mechanism* describes a research concept, **not** a verified implementation, operating capability, or procedural instruction.
